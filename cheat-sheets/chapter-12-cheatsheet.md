# Chapter 12 Cheat Sheet: Full Practice Exam Simulation & Time-Management

## Time Budget Framework (120 min / 40-60 Qs)
| Segment | Approx. Time | Notes |
|---|---|---|
| Standalone questions | ~1-1.5 min each | Recalculate pace every ~10 questions |
| Case study (5-6 Qs) | ~20-25 min total | Skim once, targeted re-read per question |
| Final review buffer | 5-10 min | Reserve, don't spend early |

**Pacing rule:** After every block of questions, check `(time remaining) / (questions remaining)`. If it drops below your per-question budget, speed up on lower-confidence items — don't slow down further.

## Case Study Reading Strategy
| Pass | Action |
|---|---|
| 1st (Skim) | Read scenario once fully, note key facts (roles, licenses, existing config, constraints) |
| 2nd (Targeted) | For each question, re-read only the referenced section — don't re-read the whole case |

## Flagging & Revisit Rules
- Flag anything you're not 100% confident on — don't deliberate long on first pass.
- Always select a best-guess answer before flagging (never leave blank).
- On revisit, spend time proportional to confidence gap, not question order.

## Elimination Strategy for Distractors
| Step | Action |
|---|---|
| 1 | Remove options citing deprecated/nonexistent features or wrong service category |
| 2 | Remove options that solve only part of the scenario's stated requirements |
| 3 | Compare remaining 1-2 options against every explicit constraint in the scenario |
| Avoid | Judging by answer length or picking the first "plausible-sounding" option |

## Drag-and-Drop / Ordering Items
1. Place confident steps first (anchors).
2. Use dependency logic ("what must happen before X") for uncertain steps.
3. Never leave default/unordered — it's guaranteed wrong.
4. Flag for revisit if time allows full re-verification.

## Final Review Priority (last 10 minutes)
1. Flagged questions in your **weakest domain** (based on practice exam history).
2. Remaining flagged questions (any domain).
3. Only if time remains: spot-check high-confidence answers.

## Golden Rules
- **Never submit a blank answer** — always guess after elimination.
- **Recalculate pace continuously**, not just once.
- **Weak domain gets review priority**, not equal time across domains.
- **Skim → Targeted re-read**, never full re-read per question.
