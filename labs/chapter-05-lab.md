# Chapter 5 Lab: Network Perimeter Controls: NSGs, Azure Firewall, WAF, DDoS

**Estimated time:** 25 minutes

## Exercise

Deploy an NSG with priority-ordered rules to restrict subnet traffic, then attach a WAF policy in Prevention mode to an Application Gateway to block SQL injection attempts

## Key takeaway

Network security layers stack from NSGs (L3/L4) up to WAF (L7); the exam tests picking the correct layer for a described threat.
