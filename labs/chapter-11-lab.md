# Chapter 11 Lab: Microsoft Sentinel & Securing AI Workloads

**Estimated time:** 25 minutes

## Exercise

Create a Sentinel scheduled analytics rule that triggers an incident on suspicious sign-ins, then attach an automation rule that runs a Logic Apps playbook to disable the user account

## Key takeaway

Sentinel ties detection to automated response, and AI workload security extends the same data-protection and monitoring principles to new AI-specific risks like prompt injection.
