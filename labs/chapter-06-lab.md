# Chapter 6 Lab: Private Connectivity & Network Segmentation

**Estimated time:** 20 minutes

## Exercise

Create a private endpoint for an Azure Key Vault, link the required private DNS zone, and verify that public access from the internet is denied while VNet-connected resources resolve to the private IP

## Key takeaway

Private Link with correctly linked private DNS is the exam's default answer whenever full network isolation for PaaS is required.
