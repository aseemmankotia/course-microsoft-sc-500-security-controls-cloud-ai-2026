# Chapter 7 Lab: Securing Virtual Machines and Disk Encryption

**Estimated time:** 20 minutes

## Exercise

Enable Just-in-Time VM access in Microsoft Defender for Cloud for an RDP port and configure Azure Disk Encryption on a Windows VM's OS disk using a Key Vault key

## Key takeaway

VM security exam questions hinge on selecting the correct encryption layer and least-exposure access model (JIT) for the scenario.
