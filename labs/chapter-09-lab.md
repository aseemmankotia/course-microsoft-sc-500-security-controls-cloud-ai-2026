# Chapter 9 Lab: App Service, Serverless & Key Vault Secrets Management

**Estimated time:** 20 minutes

## Exercise

Configure an App Service to reference a Key Vault secret via @Microsoft.KeyVault() syntax using its system-assigned managed identity, then enable purge protection on the vault

## Key takeaway

Key Vault centralizes secrets/keys/certificates, and the exam tests correctly wiring managed identities and the RBAC vs access-policy permission model.
