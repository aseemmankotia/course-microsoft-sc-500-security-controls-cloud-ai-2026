# Chapter 8 Lab: Securing Containers and Azure Kubernetes Service

**Estimated time:** 25 minutes

## Exercise

Deploy the Azure Key Vault Provider for Secrets Store CSI Driver on an AKS cluster to mount secrets as volumes and enable Microsoft Defender for Containers to scan images in Azure Container Registry

## Key takeaway

AKS security scenarios test whether secrets, network access, and image scanning are handled through Azure-native integrations rather than default Kubernetes primitives.
