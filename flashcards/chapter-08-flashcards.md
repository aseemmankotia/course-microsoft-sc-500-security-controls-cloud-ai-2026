## Chapter 8: Securing Containers and Azure Kubernetes Service — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Default rotation poll interval for the Key Vault Secrets Store CSI Driver? | 2 minutes (rotationPollInterval), enabled via --enable-secret-rotation. Exam tip: rotation updates the mounted file automatically; syncing to a K8s Secret still requires secretObjects. |
| 2 | Kubernetes version in which PodSecurityPolicy (PSP) was removed? | v1.25. Replaced by built-in Pod Security Admission (PSA) with Privileged/Baseline/Restricted profiles. Exam tip: any AKS cluster on 1.25+ cannot use PSP. |
| 3 | Azure Network Policy Manager vs Calico — node OS support? | Azure NPM = Linux nodes only. Calico = Linux AND Windows Server node pools. Exam tip: mixed-OS clusters require Calico. |
| 4 | AAD Pod Identity vs Microsoft Entra Workload Identity? | AAD Pod Identity is deprecated/retired. Workload Identity is the supported replacement using OIDC federation with no secrets stored in-cluster. Exam tip: 'pod identity migration' scenario = pick Workload Identity. |
| 5 | CLI flag to select Calico as the AKS network policy engine at cluster creation? | az aks create --network-plugin azure --network-policy calico. Exam tip: the network policy engine CANNOT be changed after cluster creation — requires a new cluster. |
| 6 | Flags to enable Workload Identity + OIDC issuer on AKS? | az aks update --enable-oidc-issuer --enable-workload-identity. Exam tip: the OIDC issuer must be enabled BEFORE creating the federated identity credential. |
| 7 | How does an AKS private cluster restrict API server access? | The API server gets a private endpoint inside the cluster's VNet plus a private DNS zone — no public IP at all. Exam tip: different from authorized IP ranges, which keeps a public IP but filters source addresses. |
| 8 | How does the Key Vault CSI driver expose secrets to pods? | Mounts secrets as files in an in-memory volume via a SecretProviderClass; optional secretObjects block syncs them to a native Kubernetes Secret for env-var consumption. Exam tip: mounting alone does NOT create a K8s Secret. |
| 9 | Does --api-server-authorized-ip-ranges apply to private AKS clusters? | No — authorized IP ranges only filter the public API server endpoint. Private clusters have no public endpoint, so this setting doesn't apply. Exam trap: picking authorized IP ranges when the requirement is 'no public exposure at all'. |
| 10 | Which admission controller enforces custom policies via the Azure Policy Add-on for AKS? | Gatekeeper (OPA-based), deployed by the Azure Policy Add-on. Exam tip: distinct from built-in Pod Security Admission, which only enforces the 3 predefined PSS profiles, not custom rules. |
| 11 | Where does Microsoft Defender for Containers get image vulnerability results from? | The Microsoft Defender Vulnerability Management engine integrated into Defender for Cloud, scanning images in ACR and correlating with running image inventory in AKS. Exam tip: requires the Defender for Containers plan enabled on the subscription, not just ACR access. |
| 12 | Pod Security Standards profile levels, least to most restrictive? | Privileged → Baseline → Restricted. Exam tip: 'Restricted' is the hardened profile tested for blocking privilege escalation, hostPath mounts, and root containers. |
